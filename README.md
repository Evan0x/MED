# Avela (Repository Root)

Avela is a healthcare discovery app.

This outer README is for the repo root only. The active app lives in [hackathon-v1](hackathon-v1/README.md).

## Workspace layout

- [hackathon-v1](hackathon-v1) — active Vite app (deploy this)
- [hackathon v.1](hackathon%20v.1) — older legacy folder

## Run locally (active app)

```bash
cd hackathon-v1
npm install
cp .env.example .env
npm run dev
```

Open http://localhost:5173

## Deployment

Deploy using `hackathon-v1` as the root directory.

See complete setup, environment variables, API routes, and production notes in [hackathon-v1/README.md](hackathon-v1/README.md).
